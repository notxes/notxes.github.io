Enterprise Segmented Cybersecurity Homelab

A multi-system environment for enterprise-style networking, systems administration, and defensive security work.

VLANsCiscoOPNsenseProxmoxActive Directory

Objective

Build a reusable environment for network engineering, infrastructure administration, and controlled security testing.

Implementation

  • Designed Management, Red Team, Victim Lab, Blue Team, DMZ, and IoT network zones.
  • Configured OPNsense routing and Cisco managed switching with VLANs and traffic mirroring.
  • Deployed Active Directory, Windows 11 victim endpoints, and a file server.
  • Built Proxmox virtual machines and VLAN-aware virtual networking.
  • Integrated Security Onion, a dedicated AI server, NAS storage, and Raspberry Pi services.

Outcome

The lab supports repeatable connectivity, segmentation, firewall, Windows administration, virtualization, and defensive monitoring exercises.

Network design

OPNsense controls routing between security zones. Managed switching separates workloads and provides mirrored traffic to monitoring systems.

Lab VLANs
