Security Onion Monitoring Environment

Network security monitoring using Zeek, Suricata, SPAN-mirrored traffic, and Security Onion investigation tools.

Security OnionZeekSuricataCisco SPAN

Objective

Establish visibility into traffic across segmented lab systems and practice alert analysis and event investigation.

Implementation

  • Installed and configured Security Onion with management and monitoring interfaces.
  • Integrated mirrored traffic from Cisco switching through a SPAN destination port.
  • Used Zeek connection and protocol records alongside Suricata network alerts.
  • Reviewed network events, logs, alerts, and investigation data.
  • Troubleshot switch mirroring and monitoring visibility.

Outcome

Developed hands-on experience deploying monitoring infrastructure, investigating security events, and troubleshooting network telemetry in a controlled lab.

Monitoring workflow

Lab traffic is mirrored from the Cisco switch to the Security Onion monitoring interface. The environment provides network metadata and IDS alerts for analysis of controlled testing activity.

Related systems

  • Cisco managed switching with SPAN
  • Security Onion
  • Zeek
  • Suricata
  • Separate attacker and victim test networks
