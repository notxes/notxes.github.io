Proxmox Virtualization Infrastructure

Virtualized Windows, Linux, and security infrastructure supporting controlled administrative and cybersecurity scenarios.

Proxmox VEWindows ServerLinuxVirtual networking

Objective

Deploy flexible, virtualized infrastructure for testing, troubleshooting, and isolated security workloads.

Implementation

  • Installed and managed multiple Proxmox virtualization hosts.
  • Created Windows Server, Windows 11, Kali, and Ubuntu virtual machines.
  • Configured VLAN-aware Linux bridges and virtual networking.
  • Separated attacker, victim, defensive, and infrastructure workloads.
  • Supported virtualized domain services and security monitoring.

Outcome

Developed operational experience with host administration, VM deployments, virtual networking, and workload separation across multiple hosts.

Infrastructure roles

The lab uses a primary Proxmox host alongside dedicated Red Team and Blue Team hosts. A separate Proxmox system is available for additional infrastructure development.

Workloads

  • Active Directory and Windows clients
  • Linux and Kali systems
  • Victim lab VMs
  • Monitoring and investigation tools
  • Administrative services
