Independent Cybersecurity Lab

Security Onion Monitoring Environment

Network security monitoring using Zeek, Suricata, mirrored VLAN traffic, and Security Onion investigation tools.

Objective

Establish visibility into network traffic across segmented systems and practice alert analysis and event investigation.

Implementation

  • Installed and configured Security Onion.
  • Configured management and monitoring interfaces.
  • Integrated mirrored traffic from Cisco switches.
  • Reviewed network events, alerts, logs, and traffic data.
  • Troubleshot SPAN configuration and monitoring visibility.

Evidence

Security Onion dashboard, alert review, and Hunt interface screenshots.

Outcome

Developed practical experience deploying monitoring infrastructure, investigating events, and troubleshooting network telemetry in a controlled cybersecurity lab.

Independent Network Security Lab

OPNsense Firewall & VLAN Segmentation

Network security design using VLAN-based separation, firewall access controls, routing, and trust boundaries.

Objective

Restrict unnecessary network communication while preserving explicitly permitted connections between lab services.

Implementation

  • Configured OPNsense VLAN interfaces and network routing.
  • Created allow and deny rules for inter-VLAN communication.
  • Separated management, security, attacker, victim, and IoT networks.
  • Troubleshot DNS resolution, routing, and connectivity.
  • Configured and evaluated remote access controls.

Evidence

OPNsense interface and firewall policy configuration screenshots.

Outcome

Built a segmented lab environment for studying least-privilege network access and firewall behavior. Formal effectiveness testing remains part of ongoing research.
